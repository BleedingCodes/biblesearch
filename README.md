# biblesearch
Want to know a specific verse, chapter to a book or a book. All you need is the name of the book and verse. Good way t test if you know the works to each verse.  

# This is my way of Sharing Gods word from the WEB Bible

# (🤮Windows🤮):

Download BibleSearch-Windows.zip, right-click it, and choose Extract All. Don’t run it from inside the zip.
Open the extracted folder, then BibleSearch, and double-click the exe.
If Windows says “Windows protected your PC”, click More info, then Run anyway.
He types a verse, chapter, or book, such as john 3:16, and presses Enter.

# (🤘Linux🤘):

Download BibleSearch-Linux.tar.gz.
Run tar -xzf BibleSearch-Linux.tar.gz, then cd BibleSearch.
Run ./yourscript john 3:16, or just ./yourscript for the prompt.
